# Distance Formula Calculator
   #### - This calculator will be used to calculate the distance between points on a cartesian plane 

## How do I use this file

- Download file on Python
- Run the program
- Enter inputs needed
- Wait for final output

## Inputs needed
- x1
- y1
- x2
- y2

## Sample output

### Inputs
- x1 = 2
- y1 = 3
- x2 = 4
- y2 = 5

### Output

- 2.83
